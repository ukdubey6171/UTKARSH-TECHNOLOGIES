# Utkarsh Technologies Limited – Website

## Open in VS Code
File > Open Folder > select this folder. Install the Live Server extension, right-click index.html > Open with Live Server.

## Pages
Main site: index.html, construction.html, it-solutions.html, core-team.html, publications.html, book.html
Marketing & Advertisement site: marketing.html, about.html, services.html, packages.html, team.html, contact.html

## Where to edit
- Colours: css/style.css (top of the file)
- Main site menu/footer: js/site.js
- Marketing site menu/footer: js/app.js
- Logo: images/logo.png (add your own)
- Book cover: images/after-hours-cover.jpg
- sitemap.xml and robots.txt are for Google.

## New features
- enquiry.html: enquiry / contact form (Name, Phone, Email, Department, Service, Package, Location, Message). Connect it in js/config.js (Formspree address or email).
- package-selector.html: suggests a marketing package from purpose + services.
- FAQ: edit js/data.js.
- AI-style chat assistant: js/chatbot.js (answers from a built-in knowledge base; edit the KB list to add answers).
- Company profile: Utkarsh-Technologies-Company-Profile.pdf
- Favicon: favicon.ico, favicon-48.png, favicon-192.png, apple-touch-icon.png
- GSTIN 09BHOPD3588E1Z2 is shown in the footers, enquiry page and profile.
- Home page "Coming soon" section for Aetherion: images/aetherion-*.webp, styles at the end of css/extra.css.
- Animations: css/motion.css and js/motion.js (scroll reveal, button ripple, page fade, count-up numbers). Only transform and opacity are animated, so the site stays smooth.
