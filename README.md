# Utkarsh Technologies Limited – Website

Pages: index.html (Home), about.html, services.html, packages.html, contact.html

## Open in VS Code
1. File > Open Folder > select this folder.
2. Install the "Live Server" extension (VS Code will suggest it).
3. Right-click index.html > "Open with Live Server".
(You can also just double-click index.html to open it in a browser.)

## Edit
- Colours/theme: css/style.css (variables at the top)
- Shared menu/footer/address/phone: js/app.js
- WhatsApp number: contact.html (UTK_WHATSAPP)
- Package contents: packages.html

## Change colours
Open css/style.css. The colour list is at the very top (:root). Change the hex codes there; the whole site updates.

## Add your logo
Save your logo as images/logo.png. It then shows in the menu and footer on every page. Until then a small moon icon is shown.
